# Grove releases

Downloads and auto-update feed for [Grove](https://github.com/devlinpeck/devlinmux) —
Claude Code workspaces in containers.

Grab the latest `.dmg` (macOS) or `.exe` (Windows) from
[Releases](https://github.com/devlinpeck/grove-releases/releases). Installed
apps update themselves from here automatically.

Source lives in the private `devlinmux` repo; this repo only hosts installers.
